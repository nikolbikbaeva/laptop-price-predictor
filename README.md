# Laptop Price Predictor · Team 3

A laptop data-science project: explore 1,560 scraped laptop listings, compare compact price-prediction models, and estimate a fair price for a laptop from its specifications.

**Team 3 (EADA G1):** Alejandro Angel Montilla · Christian Freiherr von Jenisch · Nikol Bikbaeva · Royana Araujo Cardoso · Smith Bhor

## Compare price-prediction models

Open [`reports/laptops_models.html`](reports/laptops_models.html) for the completed, offline model benchmark. It compares a median-price baseline, linear regression, ridge regression, k-nearest neighbours, a decision tree, a random forest and gradient boosting. Interactive charts, a sortable metrics table, an error analysis, model settings, metric definitions and links to the result CSVs are embedded in the HTML.

```bash
source .venv/bin/activate
python scripts/train_models.py
```

The benchmark uses 1,548 cleaned laptops and 36 inputs. It holds out a random 20% test set (310 laptops, `random_state=42`), compares the models with 5-fold cross-validation on the remaining 1,238 laptops, selects the lowest mean validation RMSE, refits on the full training set and scores every model once on the test set. All learned models predict log prices; reported errors are in original price units.

| Model | Validation RMSE | Test R² | Test MAE |
|---|---:|---:|---:|
| **Gradient boosting** (selected) | **104** | **0.973** | **52** |
| Random forest | 135 | 0.958 | 53 |
| Decision tree | 164 | 0.929 | 59 |
| k-nearest neighbours | 334 | 0.777 | 239 |
| Linear regression | 443 | 0.633 | 152 |
| Ridge regression | 445 | 0.632 | 150 |
| Median baseline | 689 | −0.077 | 510 |

The same laptop model often appears several times with different memory or storage, so a random split is optimistic. A second check (GroupKFold by `TypeName`) holds out whole laptop models: gradient boosting reaches R² 0.94 with an average error of 60 on models it has never seen. The selected model relies mostly on memory (77% of feature importance), SSD size (14%) and a dedicated graphics card (4%).

The selected pipeline and its column list are saved in `models/laptops/`. Make example predictions with:

```bash
python scripts/predict_prices.py \
  --input models/laptops/example_laptops.csv \
  --output reports/example_predictions.csv
```

New input CSVs must include `Company, Cpu, Gpu, Inches, X_res, Y_res, ppi, TouchScreen, Ips, Dedicated_Gpu, Ram_GB, Weight_kg, SSD, HHD` with the original column names. Extra columns are kept in the output but not used. Brands that are not in the training data get no brand signal.

To refresh the HTML from saved results without retraining:

```bash
python scripts/train_models.py --report-only
```

If needed, install the model dependencies in the activated environment:

```bash
python -m pip install -r requirements-models.txt
```

Custom paths are available through `--help` on every script. Defaults resolve relative to the project, so the scripts also work from another current directory. The saved pipeline, metrics, test predictions, data checksum, exact test-set membership and package versions make the run reviewable and reproducible.

## Start with the EDA mini-course

Open [`courses/eda/index.html`](courses/eda/index.html) in a browser for a beginner-friendly, approximately 20-minute introduction to exploratory data analysis. No coding, installation or web server is needed.

Six short lessons cover asking a question, reading a table, distributions, relationships, data quality and communicating findings. The course includes interactive charts built from the real laptop data, quick checks with explanations, a mean-versus-median experiment and a downloadable personal EDA note. Progress and notes are stored in the current browser when storage is available. All lessons can be printed or saved as a PDF.

The HTML file is self-contained and works offline. It embeds a snapshot of the cleaned data and is not regenerated by `scripts/eda.py`.

## Generate the EDA report

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements-eda.txt
python scripts/eda.py
```

The script reads the full dataset and produces `reports/laptops_eda.html`. Its interactive charts, tables and chart library are embedded, so the report works offline and can be shared as one file. Hover over charts for details, drag to zoom and double-click to reset. Search the column guide to find individual columns.

To choose another copy of the CSV or a report destination:

```bash
python scripts/eda.py --input dat/laptops/laptop_scrap_data.csv --output reports/laptops_eda.html
```

## Data and cleaning

`dat/laptops/laptop_scrap_data.csv` is kept exactly as downloaded (1,563 rows, 21 columns). Cleaning happens in code, in `scripts/common.py`, so every script uses the same rules:

| Check | Rows | Decision |
|---|---:|---|
| Completely empty rows | 3 | Removed |
| `Weight_kg` = 0 (impossible) | 11 | Left out |
| `Total_Storage_GB` = 0 (impossible) | 1 | Left out |
| Used for analysis and modeling | 1,548 | — |

Nothing is imputed. The source does not label the currency of `Price`; it is treated as USD. CPU and GPU names are free text and are converted into a CPU vendor, a CPU tier (1 = basic … 9 = top), and an RTX class and generation.

## Project folders

- `courses/eda/index.html`: self-contained introductory EDA course with six interactive lessons.
- `dat/laptops/laptop_scrap_data.csv`: complete original CSV, 1,563 rows and 21 columns.
- `dat/laptops/laptops_starter.csv`: five simple inputs and the price, for first exercises.
- `dat/laptops/data_description.txt`: column guide.
- `dat/laptops/source.json`: provenance, checksum and starter-column mapping.
- `scripts/common.py`: shared loading, cleaning and feature engineering.
- `scripts/eda.py`: builds the EDA report.
- `scripts/train_models.py`: validates, selects, tests and saves the models; builds the model report.
- `scripts/predict_prices.py`: prices new laptops with the saved model.
- `scripts/templates/`: Jinja2 templates for the HTML reports.
- `models/laptops/`: selected pipeline, test and validation metrics, test predictions, feature importance, metadata and example laptops.
- `reports/`: generated HTML reports and example predictions.
- `portal/`: source of the FairSpec web app that turns the price estimate into a buyer and seller tool; see [`portal/README.md`](portal/README.md).
- `requirements-eda.txt`, `requirements-models.txt`: pinned Python dependencies.

## Limitations

- Scores apply to this scraped dataset at one point in time, not to the current market or to used laptops.
- The currency is not labelled.
- Rare, expensive configurations have the largest errors because few similar laptops exist in the data.
- No hyper-parameter search was done; settings are fixed and simple.
